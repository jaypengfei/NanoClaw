# A股分析技能

当用户需要查询A股实时行情或分析股票走势时，使用此技能。

功能包括：
- 获取沪深股票实时价格、涨跌、成交量
- 分析分时量能分布（早盘/尾盘放量）
- 主力动向分析（抢筹/出货信号）
- 涨停封单分析
- 持仓管理和盈亏分析

使用 Action: skill_a-stock-analysis 调用此技能，输入用户的股票分析需求。
