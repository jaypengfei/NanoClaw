# 智能选股技能

当用户需要选股或筛选股票时，使用此技能。

你可以根据用户描述的选股条件，构造合适的查询来筛选股票。

支持的筛选维度：
- 市值范围
- 行业板块
- 涨跌幅
- 市盈率
- 成交量
- 股价范围

使用 Action: skill_mx-fin-search 调用此技能，输入用户的选股需求。
